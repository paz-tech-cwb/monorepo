# Paz Curitiba Backend

This is a backend API built with [NestJS](https://nestjs.com/).

## 🚀 Features
- Church Information: foundational context about the church
- Member Journey: guidance for new or existing members
- Life Group: opportunities to connect in smaller groups
- Courses: growth and discipleship resources
- Announcements: news and updates
- Contribution: giving and donations

## 📦 Installation

```bash
# Clone the repo
git clone https://github.com/paz-tech-cwb/backend paz-cwb-backend

# Navigate to the directory
cd paz-cwb-backend

# Install dependencies
npm install
```

## 🧪 Running the App

```bash
# Development
npm run start:dev

# Production
npm run build
npm run start:prod

# Unit tests
npm run test

# e2e tests
npm run test:e2e
```
