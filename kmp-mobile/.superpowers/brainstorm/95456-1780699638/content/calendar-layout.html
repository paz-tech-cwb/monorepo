B — Sticky strip + collapsible day groups

Same sticky week strip, but the list below groups events by day. Today auto-expands; other days show a summary row that taps to expand. More information density, slightly more complex interaction.

Both options: today gets a gold dot + filled pill. Days with events get a small blue dot. Days with no events show nothing.
